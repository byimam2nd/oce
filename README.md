## 📲 Installation

In CloudStream go to **Settings → Extensions → Add repository** and add one of:

- **Stable:** `https://raw.githubusercontent.com/byimam2nd/oce/master/repo.json`
- **Beta:** `https://raw.githubusercontent.com/byimam2nd/oce/master/repo-beta.json`
